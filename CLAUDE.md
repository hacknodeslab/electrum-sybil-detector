# Project conventions

## Commits

- Subject: 1 line, lowercase, ≤50 chars when possible, format `topic: verb phrase`.
- No body unless the diff genuinely cannot be understood without it.
- Keep the `Co-Authored-By: Claude` trailer.

Examples from this repo's git log:

```
phase-1 closeout: 3 validations done
prd: integrate phase-1 closeout validations + pass
```
